Practice Guidance

When using external resources, focus on understanding:

1. How a method is declared.
2. How a method is called.
3. How arguments are passed to parameters.
4. How values are returned.
5. How "void" methods differ from value-returning methods.
6. How local variables are scoped.
7. How methods can improve code reuse and organization.
