Topic Summary

A method is a reusable block of code that performs a specific task.

A method can:

- Receive input through parameters.
- Perform processing.
- Return a value.
- Perform an action without returning a value.

The four main method forms are:

1. Without parameters and without a return value.
2. Without parameters and with a return value.
3. With parameters and without a return value.
4. With parameters and with a return value.

Parameters are variables declared in the method definition.

Arguments are the actual values passed when the method is called.

The "return" statement returns a value from a method and immediately
ends that method's execution.

Local variables are accessible only within their scope.

A variable declared inside a block such as an "if" statement cannot be
accessed outside that block.

Methods should have clear responsibilities, meaningful names, and
should be reusable when appropriate.

Common Mistakes

- Confusing parameters with arguments.
- Using an incorrect return type.
- Forgetting to return a value from a non-void method.
- Trying to use a local variable outside its scope.
- Writing code after an unconditional "return".
- Printing a calculation result inside a method when the result should
  be reusable.
- Creating unnecessary parameters.
- Giving methods unclear or meaningless names.
- Making one method responsible for too many unrelated tasks.

Summary

Methods allow Java programs to divide functionality into small,
focused, reusable units.

A well-designed method should have a clear purpose, appropriate
parameters, an appropriate return type, and a predictable result.
