# Static Members — Resources

## 1. Official Java Documentation

### Java Tutorials — Classes and Objects

https://docs.oracle.com/javase/tutorial/java/javaOO/

Provides foundational explanations of Java classes, objects, fields, and methods.

**Recommended for:** Reviewing the relationship between classes and objects.

### Java Language Specification — Chapter 8: Classes

https://docs.oracle.com/javase/specs/jls/se25/html/jls-8.html

Defines the Java language rules for classes, including static fields, static methods, and class initialization.

**Recommended for:** Understanding the formal rules governing static members.

### Java Language Specification — Chapter 15: Expressions

https://docs.oracle.com/javase/specs/jls/se25/html/jls-15.html

Describes Java expressions, including method invocation and access to fields.

**Recommended for:** Further investigation of member access and method calls.

## 2. Practice and Learning

### Dev.java — Learn Java

https://dev.java/learn/

Provides Java learning materials covering language fundamentals and object-oriented programming.

**Recommended for:** Reviewing Java fundamentals and strengthening conceptual understanding.

### Practice Exercises

Create small Java programs to investigate the following questions:

- What happens to a static field when multiple objects are created?
- How does modifying an instance field differ from modifying a static field?
- Why can a static method access static fields directly but not instance fields?
- How can a static method access an instance field through an object reference?
- Why does a constructor increment a shared static counter?
- Why does a static counter not automatically track the number of objects currently in memory?

## 3. Study Guidelines

- Start with the official Java tutorials.
- Use the Java Language Specification when you need precise language rules.
- Test your understanding with small programs.
- Predict the output before running each program.
- Record important observations in `Notes.md`.

## 4. Completion Goal

After studying these resources, you should be able to explain the difference between static and instance members, apply them in simple Java classes, and predict their behavior without relying on memorization.
