## Additional Practice Ideas

Experiment with small classes such as:

- Book
- Student
- Car
- Product
- Employee
- Computer

For each class, practice:

- Defining instance variables.
- Creating one object.
- Creating multiple objects.
- Assigning different state to each object.
- Defining a simple instance method.
- Calling the method through different objects.
- Assigning one reference variable to another.
- Observing the difference between separate objects and shared references.

---

## Practice Focus

When experimenting, always ask:

- How many objects were created?
- How many reference variables exist?
- Which reference points to which object?
- What is the current state of each object?
- Does changing one object affect another?
- Did new create another object?
- Is a new reference being created or a new object?
