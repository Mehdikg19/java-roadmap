# Constructors

## Overview

This lesson introduces Java constructors and their role in initializing objects.

## Topics Covered

* Constructor basics
* No-argument constructors
* Parameterized constructors
* Default constructor
* Constructor overloading
* Constructor vs method
* Object initialization
* Constructor execution during object creation

## Playground

`Playground.java` contains experiments with different constructors and object creation.

## Key Rule

A constructor:

* has the same name as its class
* has no return type
* initializes an object
* runs when an object is created with `new`
