### 2. Practice Examples

Practice writing programs that:

- Count numbers upward.
- Count numbers downward.
- Print even and odd numbers.
- Calculate sums using loops.
- Repeat actions until a condition changes.

---

### 3. Debugging Practice

When a while loop does not work:

Check:

- Is the initial value correct?
- Is the condition correct?
- Is the variable updated inside the loop?
- Can the condition ever become false?

# Additional Practice Ideas

## Beginner Level

1. Print numbers from 1 to 100 using while.

2. Print all odd numbers between 1 and 50.

3. Calculate the sum of numbers from 1 to 100.

4. Print a countdown from 20 to 0.

---

## Intermediate Level

5. Ask the user for a number and print its multiplication table.

6. Keep asking the user to enter a password until the correct password is entered.

7. Count how many numbers between 1 and 100 are divisible by 5.

8. Reverse a number using a while loop.

---

## Challenge Level

9. Create a simple menu system:

Example:


1. Start
2. Settings
3. Exit


The program should continue showing the menu until the user chooses Exit.

10. Create a number guessing game:

- Generate a secret number.
- Ask the user to guess.
- Continue until the correct number is entered.

---

## Key Reminder

A good while loop should always have:

1. An initial value.
2. A condition.
3. A change that moves the loop toward termination.
