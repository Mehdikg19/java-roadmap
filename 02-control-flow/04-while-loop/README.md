# 04 - While Loop

## Overview

The while loop is used to repeat a block of code as long as a condition remains true.

Unlike a for loop, a while loop is usually used when the number of iterations is unknown before the program starts.

---

## Learning Objectives

After completing this lesson, you will be able to:

- Understand how a while loop works.
- Write simple while loops.
- Count up and count down using while.
- Avoid infinite loops.
- Know when to use while instead of for.

## Common Mistakes

- Forgetting to update the counter variable.
- Writing an incorrect loop condition.
- Creating an infinite loop.
- Using while when for is more suitable.
