Additional Practice Ideas

Practice 1

Print numbers from 1 to 100 but skip multiples of 3 using "continue".

Practice 2

Print numbers from 1 to 100 and stop at the first number divisible by both 7 and 11 using "break".

Practice 3

Use nested loops and "break" to stop only the inner loop.

Practice 4

Use nested loops and "continue" to skip a specific value of the inner loop.

Practice 5

Combine "break" and "continue" in one loop and predict the output before execution.

---

Challenge

Write a program that searches numbers from 1 to 100.

Requirements:

- Skip even numbers using "continue".
- Find the first odd number divisible by both 3 and 7.
- Print that number.
- Stop the loop using "break".

Before running the program, predict the output.
