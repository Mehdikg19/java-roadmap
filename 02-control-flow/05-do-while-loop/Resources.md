Additional Practice Ideas

Print numbers from 1 to 10 using do-while.

Print numbers from 10 down to 1.

Print even numbers from 2 to 20.

Print odd numbers from 1 to 19.

Create a simple menu that executes at least once.

Test a do-while loop with an initially false condition.

Solve the same problem using both while and do-while.

Create an intentional infinite loop and then identify and fix it.

Change < to <= and observe the difference.

Change the initial value and predict the new execution flow before running the program.

Learning Tip

Before executing a do-while program, trace:

Initial value ↓ Body ↓ Update ↓ Condition ↓ Repeat or Exit 

Always predict the output before execution.
